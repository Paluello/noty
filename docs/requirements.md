# Requisiti

Priorità: **M** = obbligatorio, **S** = importante, **C** = se c'è tempo. Versioni: vedi [roadmap](roadmap.md).

| ID | Requisito | Priorità | Versione |
|---|---|---|---|
| ORG-1 | Libreria con cartelle e sottocartelle (livelli illimitati) | M | 0.1 |
| ORG-2 | Quaderni dentro le cartelle, composti da pagine | M | 0.1 |
| ORG-3 | Vista a griglia: le cartelle hanno un'icona, i quaderni una copertina | M | 0.1 |
| ORG-9 | Copertina del quaderno: colore a scelta da una palette allegra (assegnato a caso alla creazione) oppure una foto o un file come immagine | M | 0.1 |
| ORG-4 | Ordinamento per data di modifica, data di creazione, nome o manuale; scelta salvata per cartella | S | 0.2 |
| ORG-5 | Preferiti e sezione "Recenti" | S | 0.2 |
| ORG-6 | Rinomina, sposta, duplica, elimina (con Cestino di 30 giorni) | M | 0.1 |
| ORG-7 | Ricerca per nome di quaderno o cartella | S | 0.2 |
| ORG-8 | Ricerca nella scrittura a mano (OCR) | C | 0.5 |
