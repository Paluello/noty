# Flussi principali

## F1. Scrivere subito (il flusso più importante)
Apri l'app → Libreria (griglia) → tocca un quaderno → si apre sull'**ultima pagina vista** con l'**ultimo strumento** usato → scrivi.
**Obiettivo: ≤ 2 tocchi, < 1 s di apertura per un quaderno da 100 pagine.**

## F2. Nuovo quaderno
Libreria → [+ Nuovo] → Quaderno → scegli sfondo → Crea → pagina 1 aperta.
Alternativa: [+ Nuovo] → Cartella → nome → Crea.

## F3. Organizzare
Pressione prolungata → Sposta → scegli la cartella dall'albero; oppure trascina sulla cartella (anche nella barra laterale).

## F4. Cambiare strumento e colore mentre scrivi
- Tocca lo strumento / il colore nella barra.
- Doppio tocco della Pencil → azione configurata (predefinita: passa alla gomma e torna indietro).
- Righello: si attiva dalla barra e si muove con due dita.

## F5. Selezionare e modificare
Lazo → circonda i tratti → menu contestuale: Taglia, Copia, Duplica, Colore, Elimina; trascina per spostare, maniglie per ridimensionare.

## F6. Registrare una lezione (v0.4)
Editor → ⋯ → Registra → la registrazione continua anche se blocchi l'iPad o cambi app → Stop.
Più registrazioni per quaderno, in elenco. Riproduzione → tocca un tratto per saltare a quel momento.

## F7. Esportare
- Un quaderno: ⋯ → Esporta PDF → foglio di condivisione (File, AirDrop, stampa).
- Tutto: Impostazioni → Archiviazione → Esporta tutto → archivio `.zip` con la struttura delle cartelle, un PDF per quaderno e i file originali.

## F8. Bloccare
Pressione prolungata su un quaderno → Blocca. All'apertura viene chiesto Face ID; la miniatura viene sfocata.

## F9. Recupero
Elimina → va nel Cestino (30 giorni) → Ripristina o Elimina definitivamente.
