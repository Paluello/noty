# Gesti e input

## Apple Pencil
| Gesto | Azione |
|---|---|
| Scrivere | Strumento attivo |
| Doppio tocco (Pencil 2 / Pro) | Configurabile: gomma↔precedente (predefinito), mostra palette, nessuna azione |
| Squeeze (Pencil Pro) | Configurabile: mostra palette strumenti (predefinito) |
| Tieni fermo a fine tratto | Riconoscimento forma (se attivo) |
| Hover (iPad compatibili) | Anteprima della punta |

## Dita (con "le dita scrivono" disattivato, impostazione predefinita)
| Gesto | Azione |
|---|---|
| 1 dito trascina | Scorre le pagine |
| 2 dita pizzica | Zoom (fino al 400%; doppio tocco per tornare al 100%) |
| Tocco a 2 dita | Annulla |
| Tocco a 3 dita | Ripeti |
| Pressione prolungata su caselle di testo o immagini | Menu contestuale |

Il palmo viene ignorato grazie alla politica "solo Pencil".

## Tastiera esterna (opzionale)
⌘Z / ⇧⌘Z annulla/ripeti · ⌘N nuovo quaderno · ⌘F cerca · Esc esce dalla modalità concentrazione.
