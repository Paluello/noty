# ADR-0015: Localizzazione it/en e lingua della documentazione
- **Stato**: Accettato · **Data**: 2026-10-09

## Decisione
- UI con **String Catalog** (`Localizable.xcstrings`), in inglese (lingua base) e italiano.
- Codice, commenti, issue e commit in **inglese** (per i contributori internazionali).
- Documentazione di progetto: in italiano in fase di progettazione, **tradotta in inglese prima di aprire il repository ai contributi**.
