# ADR-0001: Registrare le decisioni architetturali
- **Stato**: Accettato · **Data**: 2026-10-09

## Contesto
Il progetto è pubblico e aperto ai contributi: chi arriva deve capire *perché* le cose sono fatte in un certo modo.

## Decisione
Usiamo gli ADR in `docs/adr/`, numerati e immutabili. Una PR che cambia una decisione architetturale deve includere un ADR.

## Conseguenze
Un po' di lavoro in più per ogni decisione, ma meno discussioni ripetute.
